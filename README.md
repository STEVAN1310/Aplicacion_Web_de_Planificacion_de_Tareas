⚔️ GOD OF TASKS

Aplicación web de planificación y gestión de tareas gamificada

📌 Descripción

**GOD OF TASKS** es una propuesta de aplicación web diseñada para ayudar a los usuarios a organizar sus tareas diarias mediante una experiencia inspirada en los videojuegos, combinando una estética cyberpunk con elementos visuales épicos.

El proyecto busca convertir las actividades cotidianas en misiones, incentivando la productividad a través de objetivos, recompensas y seguimiento del progreso.

## 🎯 Objetivo

Diseñar una interfaz intuitiva y atractiva que permita planificar actividades, establecer prioridades y visualizar el progreso personal de manera motivadora.

## ✨ Características propuestas

- 📋 Gestión de misiones y tareas diarias.
- 🔥 Sistema de prioridades y niveles de dificultad.
- ⭐ Puntos de experiencia (XP) y progresión de nivel.
- 🗓️ Seguimiento de rachas diarias.
- 👹 Desafíos especiales o jefes finales.
- ⏱️ Temporizador de concentración.
- 📊 Estadísticas de progreso semanal.

## 🎨 Diseño

La interfaz combina dos estilos visuales:

- **Cyberpunk:** fondos oscuros, detalles neón y elementos futuristas.
- **Inspiración épica:** acentos rojos, símbolos de combate y una estética de misiones.

## 🛠️ Tecnologías y herramientas

- **Figma:** diseño y creación del wireframe.
- **GitHub:** control de versiones y documentación del proyecto.

*Las tecnologías de desarrollo se definirán durante la implementación de la aplicación.*

## 🚧 Estado del proyecto

Actualmente, el proyecto se encuentra en la fase de diseño del wireframe y definición de funcionalidades.
